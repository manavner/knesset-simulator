# סימולטור הכנסת

אפליקציית ווב (קובץ HTML יחיד, בלי build) לבחירות לכנסת:

- **תוצאות אמת** של הבחירות לכנסות 21–26 (אפריל 2019 – אוקטובר 2026): קולות, אחוזים, מנדטים והסכמי עודפים.
- **חלוקת מנדטים** בשיטת בדר-עופר עם אחוז חסימה (3.25%) והסכמי עודפים. החישוב משחזר בדיוק את התוצאות הרשמיות בכל שש מערכות הבחירות.
- **סימולציה**: קובעים אחוז לכל מפלגה, מוסיפים/מוחקים מפלגות, משנים אחוז חסימה וסך קולות.
- **גושים וקואליציה**: שיוך כל מפלגה לגוש, השוואה מול 61, ובודק קואליציה.

תוצאות 2026 הן ספירה סופית של ועדת הבחירות, לפני האישור הרשמי (4.11.2026).

## הרצה מקומית
פותחים את `index.html` בדפדפן. אין תלויות.

## פריסה
אתר סטטי. ב-Vercel: Framework Preset = Other, בלי Build Command, Output Directory = `.`

מקורות: ועדת הבחירות המרכזית (דרך ויקיפדיה ו-votes26.bechirot.gov.il).
